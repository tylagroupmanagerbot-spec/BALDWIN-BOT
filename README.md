# BALDWIN-BOT

A production-ready WhatsApp bot built with Baileys for Render deployment. Includes QR code login and pairing-code login, owner configuration, group moderation commands, and a basic command system.

## Features
- WhatsApp Web/Pairing login support
- QR code scanning support for desktop terminals
- Pairing code support for mobile sessions
- Bot profile setup with anime-inspired profile image
- Full command handler loader
- Group moderation commands 
- Render-ready deployment config

## Quick start

1. Install dependencies:
   npm install
2. Start the bot:
   npm start
3. Open the terminal QR code or use pairing code in the Render logs.

## Render deployment
- Create a new Web Service from this repository.
- Start command: `npm start`
- Add environment variables as needed.
